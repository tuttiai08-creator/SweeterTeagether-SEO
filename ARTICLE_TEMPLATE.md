Every research-backed draft uses this structure. Agents fill it in a file under `content/drafts/` (or `content/ready-for-review/` after a human moves it). Do not publish from this template.

Copy the block below into a new markdown file named `YYYY-MM-DD-slug-draft.md`.

---

## Delivery notes for agents

- Research notes go in `content/research/` using the same query and date; they are not the public article.
- The “full article” section is the only body that might later be copied to the CMS — still **not published by the agent**.
- If sources are thin, submit a short research file and **do not** pad the full article.
- SEO title, meta, slug, and excerpt are proposals. A human may change them before publish.
